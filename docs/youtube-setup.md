# Як підключити YouTube: покрокова інструкція

Для людини, яка бачить ці екрани вперше. Назви кнопок я наводжу англійською в лапках, бо
Google Cloud Console за замовчуванням англомовна. Якщо у вас український інтерфейс, шукайте
кнопки за місцем, а назви на екрані можуть трохи відрізнятись від моїх.

Що вийде в кінці: у папці проєкту `C:\yt-factory` лежить файл `credentials.json` (це «паспорт»
програми), а після одного входу в браузері з'являється `secrets\token.json` (це «ключ», який
дозволяє програмі завантажувати відео на ваш канал). Обидва файли секретні: нікому не
надсилайте, нікуди не викладайте. Git їх ігнорує.

## 0. Що має бути готово до початку

- Google-акаунт, на якому створено ваш YouTube-канал.
- **Канал підтверджено за телефоном**: https://www.youtube.com/verify. Без цього YouTube не
  дозволяє відео довші за 15 хвилин (наші по 30) і власні обкладинки.

## Частина А. Google Cloud Console

### 1. Відкрити консоль
Зайдіть на https://console.cloud.google.com/ під тим самим акаунтом. Якщо вперше, Google
попросить обрати країну й поставити галочку згоди: зробіть це й натисніть «Agree and continue».

### 2. Створити проєкт
1. Угорі зліва, поруч із написом «Google Cloud», є випадаючий список проєктів («Select a
   project» або назва проєкту). Натисніть його.
2. У вікні угорі праворуч натисніть «New project».
3. «Project name»: `yt-factory`. Решту не чіпайте. Натисніть «Create».
4. Зачекайте кілька секунд, знову відкрийте той самий випадаючий список і виберіть
   `yt-factory`. Угорі зліва має стояти саме ця назва: усе далі робиться в ній.

### 3. Увімкнути YouTube API
1. Меню ☰ (три смужки, угорі зліва) → «APIs & Services» → «Library».
2. У полі пошуку введіть `YouTube Data API v3`, відкрийте результат.
3. Натисніть синю кнопку «Enable». Дочекайтесь сторінки статистики.

### 4. Налаштувати екран згоди
1. ☰ → «APIs & Services» → «OAuth consent screen». Відкриється «Google Auth Platform». Якщо
   там написано, що вона ще не налаштована, натисніть «Get started».
2. «App name»: `yt-factory`. «User support email»: оберіть свою пошту зі списку. «Next».
3. «Audience»: оберіть **«External»**. «Next». («Internal» для особистого акаунта недоступне.)
4. «Contact information»: впишіть свою пошту. «Next».
5. Поставте галочку, що згодні з «User Data Policy». «Continue», потім «Create».

### 5. Дозволити тільки завантаження відео
1. У лівому меню «Data Access».
2. «Add or remove scopes».
3. Знайдіть у списку рядок, де в колонці «Scope» закінчується на `/auth/youtube.upload`
   (його можна відфільтрувати, вставивши в поле фільтра
   `https://www.googleapis.com/auth/youtube.upload`). Поставте галочку **лише** на ньому.
   Нічого іншого не відмічайте.
4. «Update», потім «Save».

Чому лише це: цього дозволу вистачає і для відео, і для обкладинки. Ширший дозвіл `youtube`
дав би програмі змогу керувати й видаляти все на каналі, а це зайвий ризик, якщо ключ колись
потрапить не туди.

### 6. Додати себе в тестові користувачі
Ліве меню «Audience» → розділ «Test users» → «Add users» → впишіть свою Gmail-адресу →
«Save».

### 7. Створити credentials.json
1. Ліве меню «Clients» → «Create client».
2. «Application type»: **«Desktop app»**. «Name»: `yt-factory-desktop`. «Create».
3. З'явиться вікно «OAuth client created». Натисніть «Download JSON». **Завантажте зараз:**
   пізніше Google може не показати секрет повторно, і тоді доведеться створювати клієнта
   заново.
4. Завантажений файл називається приблизно `client_secret_123456-abc.apps.googleusercontent.com.json`.
   Перейменуйте його на `credentials.json` і покладіть у `C:\yt-factory\`.

### 8. ВАЖЛИВО: опублікувати застосунок, інакше ключ помре за 7 днів
Поки статус «Testing», Google робить токен недійсним **через 7 днів**
(це написано в документації Google OAuth). Тоді «налаштувати один раз» не вийде.
1. Ліве меню «Audience». У розділі «Publishing status» стоїть «Testing».
2. Натисніть «Publish app» і підтвердіть.
3. Статус стане «In production». Може з'явитися напис, що застосунок «потребує
   верифікації»: для власного користування це не заважає, він просто лишається
   «неперевіреним» (це лише додаткове попередження під час входу в кроці Б).

Якщо «Publish app» не вдається, напишіть мені: залишимось у «Testing» і повторюватимемо Б
раз на 7 днів.

## Частина Б. Один раз увійти

1. Відкрийте папку `C:\yt-factory` у Провіднику, у рядку адреси вгорі напишіть `cmd` і натисніть
   Enter: відкриється чорне вікно.
2. Якщо бібліотеки ще не встановлено: `pip install -r requirements.txt`.
3. Запустіть:
   ```
   python scripts/youtube_auth.py
   ```
4. Відкриється браузер.
   - Оберіть акаунт, на якому ваш канал. Якщо акаунт має кілька каналів, Google спитає, який
     саме: оберіть потрібний.
   - З'явиться сторінка «Google hasn't verified this app». Це очікувано для вашого власного
     проєкту. Натисніть **«Advanced»**, потім **«Go to yt-factory (unsafe)»**.
   - Побачите дозвіл на завантаження відео («upload»). Натисніть «Continue» («Allow»).
5. Браузер напише, що можна закривати вкладку, а в чорному вікні буде
   `Saved ...secrets\token.json`. Усе, більше входити не треба.

## Частина В. Перше завантаження

1. Відкрийте `config.json` і змініть один рядок: `"youtube_publish": false` на `true`.
   `"privacy_status": "private"` лишіть: YouTube усе одно тримає відео приватними,
   поки проєкт не пройде аудит.
2. У чорному вікні: `python publish.py --video 7` (або просто `python publish.py` для
   найстаршого готового відео).
3. Відео з'явиться на https://studio.youtube.com у розділі «Content» зі статусом «Private».
   Щоб зробити його публічним, відкрийте його там і змініть «Visibility».

## Де дивитись квоту (скільки витрачено)

API не повідомляє витрату у відповіді, тож програма лише пише в лог, які запити коштують
квоту. Реальну цифру дивіться в консолі: ☰ → «APIs & Services» → «YouTube Data API v3» →
вкладка «Quotas & System limits». Там є окремі лічильники для завантажень відео та
загальних одиниць. Після першого завантаження перепишіть звідти цифри й надішліть мені.

## Якщо щось пішло не так

- «Google refused to refresh the YouTube token»: застосунок лишився в «Testing» (крок 8) або
  доступ відкликано на https://myaccount.google.com/permissions. Виправте й запустіть
  `python scripts/youtube_auth.py` ще раз.
- Не завантажується обкладинка, а відео є: канал не підтверджено за телефоном (крок 0).
- «quota»: добовий ліміт вичерпано, ліміт скидається опівночі за тихоокеанським часом.
