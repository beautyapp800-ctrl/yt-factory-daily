# GitHub: куди що натискати, щоб автоматизація запрацювала

Для людини, яка бачить ці екрани вперше. Репозиторій уже створено й код залито; лишилося
дати йому секрети (ключі), яких у коді немає навмисно.

## Що таке секрети і чому їх вносите саме ви

Ключі (Groq, Cloudflare, токен YouTube) не лежать у репозиторії: він публічний, і все, що
туди потрапило, видно всьому інтернету назавжди. GitHub має спеціальне сховище «Secrets»:
після збереження значення **нікому не показується, навіть вам**, а лише підставляється в
запуск. Тому вводите їх ви самі: я їх не бачу й не торкаюсь.

## Крок 1. Відкрийте сторінку секретів

1. Відкрийте репозиторій на github.com (адресу я надіслав у повідомленні).
2. Угорі, у ряді вкладок «Code, Issues, Pull requests, Actions...» натисніть **«Settings»**
   (крайня права вкладка, із шестірнею). Якщо її не видно, натисніть «···» у кінці ряду.
3. У лівому меню знайдіть розділ **«Secrets and variables»** і розкрийте його, потім
   натисніть **«Actions»**.
4. Відкриється сторінка «Actions secrets and variables» із двома вкладками. Лишайтесь на
   вкладці **«Secrets»**.

## Крок 2. Додайте п'ять секретів

Для кожного: натисніть зелену кнопку **«New repository secret»**, у полі **«Name»**
впишіть назву **точно так, великими літерами**, у великому полі **«Secret»** вставте
значення, натисніть **«Add secret»**.

| Name | Де взяти значення |
|---|---|
| `GROQ_API_KEY` | файл `C:\yt-factory\.env`, рядок `GROQ_API_KEY=...`: копіюйте лише те, що **після знака =** |
| `CLOUDFLARE_ACCOUNT_ID` | той самий файл, рядок `CLOUDFLARE_ACCOUNT_ID=...` |
| `CLOUDFLARE_API_TOKEN` | той самий файл, рядок `CLOUDFLARE_API_TOKEN=...` |
| `POLLINATIONS_TOKEN` | той самий файл, рядок `POLLINATIONS_TOKEN=...` (необов'язково, це запасний генератор) |
| `YOUTUBE_TOKEN_JSON` | **весь вміст** файлу `C:\yt-factory\secrets\token.json` |

**Як скопіювати значення з `.env`.** Клацніть правою кнопкою на файлі `.env`, «Відкрити за
допомогою» → Блокнот. Кожен рядок виглядає як `НАЗВА=значення`. Виділіть мишею лише
значення (усе після `=`), `Ctrl+C`, потім вставте в поле «Secret» (`Ctrl+V`). Не беріть
пробілів і лапок на краях.

**Як скопіювати `token.json`.** Відкрийте файл у Блокноті, `Ctrl+A` (виділити все),
`Ctrl+C`, вставте в поле «Secret». Це одна довга лінія тексту у фігурних дужках; вставляти
треба її всю, від `{` до `}`.

**Чого додавати не треба: `credentials.json`.** Усе, що з нього потрібно для оновлення
доступу (ідентифікатор і секрет клієнта), вже є всередині `token.json`. Зайва копія
секрету означає зайвий ризик без жодної користі.

Після додавання на сторінці має бути п'ять рядків (або чотири, якщо без Pollinations). Самих
значень ви більше не побачите, лише назви та дати. Це нормально.

## Крок 3. Перевірте, що Actions увімкнено

Вкладка **«Actions»** у репозиторії. Якщо там напис «Workflows aren't being run on this
repository» або велика кнопка **«I understand my workflows, go ahead and enable them»**,
натисніть її. У новому публічному репозиторії зазвичай уже все ввімкнено, і ви побачите
зліва в списку два пункти: **daily** і **weekly**.

## Крок 4. Перший запуск вручну

1. Вкладка **«Actions»**, зліва клацніть **«daily»**.
2. Справа над списком запусків кнопка **«Run workflow»** (випадаюче меню), у ньому знову
   зелена **«Run workflow»**.
3. Через кілька секунд з'явиться рядок із жовтим кружком (іде). Клацніть на ньому, потім на
   **«produce»**, і побачите кроки з журналом у реальному часі.
4. Повний запуск займає 1–2 години. Далі він запускатиметься сам щодня о 01:17 за UTC
   (04:17 за Києвом).

**Перший запуск, найімовірніше, покаже одну невідому**: чи дозволяє Microsoft голосу
edge-tts працювати з адреси сервера GitHub (див. README, розділ «Автоматизація»). Це
перевіряється першим кроком, ще до того, як щось витрачено, тож якщо ні, ви побачите це за
хвилину.

## Крок 5. Щоб листи справді приходили

Лист про кожен запуск приходить як сповіщення GitHub про коментар, у якому згадано вас.
Перевірте один раз: https://github.com/settings/notifications, розділ **«Email
notification preferences»**: має бути поставлена галочка біля «Participating, @mentions and
custom» і стояти ваша адреса. За замовчуванням так і є.

## Якщо щось пішло не так

- **Червоний хрестик біля запуску.** Клацніть на ньому, потім на червоному кроці: у журналі
  буде причина. Той самий текст приходить вам листом.
- **«Secret not set».** Назву секрету введено з помилкою (регістр, зайвий пробіл). Видаліть
  його кнопкою з кошиком і створіть наново.
- **Хочете зупинити автоматику.** Вкладка «Actions» → «daily» → меню «···» →
  **«Disable workflow»**. Вмикається так само.
