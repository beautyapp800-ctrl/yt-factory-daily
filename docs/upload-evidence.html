The moment itself is computed through the real time zone, so 21:00 local is correct in both summer and winter:

pipeline/upload.py
  81 def publish_at(cfg, now=None):
  82     """When YouTube should make this video public, as RFC 3339 UTC.
  83 
  84     config.publish_time local time, config.publish_days_ahead days from now. The queue of
  85     finished videos lives on YouTube rather than on disk, because the runner is disposable
  86     and seven 300 MB files cannot be carried between runs; scheduling three days out means
  87     three days of failed runs change nothing a viewer sees.
  88 
  89     The conversion is done through the real zone, not a fixed offset: Kyiv is UTC+3 in
  90     summer and UTC+2 in winter, so 21:00 local is 18:00Z for part of the year and 19:00Z for
  91     the rest, and an offset written down once would be wrong for half of it.
  92     """
  93     zone = ZoneInfo(cfg.get("timezone") or DEFAULT_PUBLISH_TIMEZONE)
  94     hour, _, minute = (cfg.get("publish_time") or DEFAULT_PUBLISH_TIME).partition(":")
  95     days = int(cfg.get("publish_days_ahead", DEFAULT_DAYS_AHEAD))
  96     local = (now or datetime.now(timezone.utc)).astimezone(zone)
  97     when = (local + timedelta(days=days)).replace(hour=int(hour), minute=int(minute or 0),
  98                                                   second=0, microsecond=0)
  99     if when <= local:
 100         when += timedelta(days=1)
 101     return when.astimezone(timezone.utc).isoformat(timespec="seconds").replace("+00:00", "Z")

3. The code that sets containsSyntheticMedia

The narration is synthetic speech and the artwork is generated, so every upload declares it. These are constants, not configuration: no setting can switch them off.

pipeline/upload.py
  49 # Set on every upload, not read from config: see the module docstring.
  50 MADE_FOR_KIDS = False
  51 CONTAINS_SYNTHETIC_MEDIA = True

They are checked on the request itself immediately before it is sent, and the upload is refused rather than sent undeclared:

pipeline/upload.py
 135 def assert_mandatory_flags(body):
 136     """The two compliance flags, checked on the request itself just before it goes out."""
 137     status = body.get("status") or {}
 138     if status.get("selfDeclaredMadeForKids") is not False:
 139         raise UploadError("status.selfDeclaredMadeForKids must be false on every upload")
 140     if status.get("containsSyntheticMedia") is not True:
 141         raise UploadError("status.containsSyntheticMedia must be true on every upload: "
 142                           "YouTube requires AI-generated content to be declared")
