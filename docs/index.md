# yt-factory

A private, automated publishing tool that produces one long-form video on Stoic philosophy a
day and uploads it to a single YouTube channel belonging to its owner. It is not a product and
is not offered to anyone else; the source is public so that what it does can be checked.

- [Privacy Policy](privacy.md)
- [Source code](https://github.com/beautyapp800-ctrl/yt-factory-daily)

It uses YouTube API Services, with one OAuth scope — `youtube.upload` — to upload a video and
set its thumbnail on the owner's own channel. It reads nothing, edits nothing and deletes
nothing. Synthetic media is declared on every upload.
